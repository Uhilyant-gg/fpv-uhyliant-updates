# ФПВ Ухилянт 2.0.8

Тестова OTA-версія для перевірки оновлення `2.0.7 -> 2.0.8` без повторного запуску Setup.exe та без запиту UAC.

## Зміни

- Посилено виявлення OpenIPC-камер через mDNS, ONVIF, Majestic/OpenIPC fingerprint і локальне `/24` сканування.
- Додано безпечне скасування пошуку та коректне завершення фонових потоків.
- Додано перевірку та відновлення локальної бази пристроїв.
- Посилено перевірку OTA manifest: формат версії, HTTPS URL, ім'я пакета та SHA-256.
- Заблоковано паралельний запуск кількох операцій оновлення.
- Завантаження OTA тепер використовує тимчасовий `.part` файл та атомарне завершення.
- `ready.json` і `launcher-state.json` записуються атомарно.
- Update helper відхиляє небезпечні ZIP-шляхи та символічні посилання.
- Додано timeout для self-test оновленої програми.
- Розширено CI: compileall, self-test, перевірка узгодженості версій, підпису manifest і відсутності приватних ключів.

## Перевірка користувачем

1. У версії 2.0.7 відкрити «Оновлення станції».
2. Натиснути «Перевірити», потім «Завантажити» та «Оновити».
3. Підтвердити запуск 2.0.8 без Setup.exe та UAC.
4. Перевірити пошук OpenIPC-камер, скасування пошуку й повторний запуск сканування.
