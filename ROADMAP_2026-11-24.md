## Execution contract

Every implementation batch follows:

`fresh main -> real gap -> implementation -> focused tests -> PR -> CI -> repair red -> merge green -> refresh main -> validation -> next evidence-backed batch`

Do not wait for the target date when a stage closes early. Continue immediately when its evidence and safety gates are satisfied.

Do not accumulate unrelated product work on a red baseline. Software-only CI never closes a hardware acceptance gate.
